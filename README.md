# 栖记 Terria 支持网站

这是栖记（Terria）iOS 应用的公开支持网站，包含隐私政策和中英文详细使用说明，不包含 Terria App 源码。

- 隐私政策：<https://hanchuan8.github.io/terria-privacy/>
- 使用说明：<https://hanchuan8.github.io/terria-privacy/guide.html>

两个页面均支持中文与 English 切换，内容以当前 iOS 版本的实际功能和数据处理边界为准。`index.html` 是隐私政策，`guide.html` 是按功能路径编写的使用说明，公共样式位于 `styles.css`。相关文件推送到 `main` 后，GitHub Actions 会自动发布到 GitHub Pages。
