详细使用说明

这份说明按 App 中的真实入口编写。每一节都先给出功能路径，再说明具体操作、保存结果和需要注意的边界。

适用于 iOS 版 1.0.1（Build 9）及相近版本 最后更新：2026 年 9 月 19 日
先记住两件事

栖记无需注册即可使用，数据默认保存在本机。iCloud 同步默认关闭，只有你在设置中主动开启后，档案和记录才会进入当前 Apple 账户的 iCloud 私有数据库。

01

开始使用

认识五个底栏入口

概览查看今天的照料、设施维护、成长摘要和最近动态。
宠物管理宠物卡片、档案、饲养箱和专业记录。
过往按日期查看、筛选、编辑或删除历史记录。
耗材管理食品、药品、垫材、设备、库存和成本。
设置管理提醒、外观、语言、同步、备份、Pro 和法律信息。

第一次添加宠物

路径概览右上角“+” → 添加宠物

  1. 填写名称，然后进入“物种”选择页。可按中文、英文或特征搜索，也可按守宫、蛇类、蜥蜴、龟鳖等分类筛选。
  2. 按需填写品系／变异、性别、获取来源和购入价格。除名称与物种外，大多数信息可稍后补充。
  3. 填写入手日期、出生日期、当前体重和当前体长；单位会跟随“设置 → 单位系统”。
  4. 已有饲养箱时可直接分配；没有时先选择“暂不分配”，保存后再建立饲养箱。
  5. 分别设置喂食、换水、清洁计划。每项都可以独立选择“间隔”或“循环”模式。
  6. 点击“保存”。宠物会出现在“宠物”页，体重或体长初始值会进入成长记录。
间隔与循环间隔模式中 0 表示每天；循环模式适合“连续执行 N 天、休息 N 天”的节奏。喂食、换水、清洁彼此独立，不会互相覆盖。

添加饲养箱

路径概览右上角“+” → 添加饲养箱

  1. 填写名称、类型和尺寸。
  2. 可分配宠物，并记录加热、UVB、日间／夜间目标温度和湿度区间。
  3. 保存后，箱体可用于环境读数、设备维护、耗材更换和批量照料。
02

概览与今日照料

查看指定日期

路径概览 → 顶部日期条 → 选择日期

日期下方有内容标记时，表示当天存在照料计划、用药或复诊事项。切换日期后，“今日照料”会同步显示该日内容；未来日期也可以用于查看计划。

处理照料事项

路径概览 → 今日照料卡片 → 今日照料

  1. 顶部汇总会显示照料总数、待处理、已完成和涉及宠物数量。
  2. 点击事项右侧圆圈完成任务。需要补充食物、重量、照片或异常信息时，进入编辑表单后再保存。
  3. 点击顶栏日期按钮可切换到其他日期；点击编辑按钮可新增或调整当天事项。

设施维护与成长概览

“设施维护”显示 UVB 灯等设备距下次维护的天数；“成长概览”显示近期体重或体长变化。点击对应卡片可进入相关饲养箱或宠物档案查看详情。

03

宠物档案

查找、排序和切换布局

路径底栏“宠物” → 左上角排序／筛选

  • 排序可选择自定义、名称、最近添加或照料状态，并可进入“调整自定义顺序”拖动排序。
  • 筛选可按宠物／箱体及宠物状态缩小范围。
  • 显示模式可在双列卡片和紧凑列表之间切换，两个模式共用同一批档案。

编辑档案

路径宠物 → 选择宠物 → 右上角编辑

  1. 点击头像可拍照或选择照片，并在裁切页拖动、缩放。
  2. 在“卡片颜色”中选择自动色、预设色或系统自定义颜色。三种方式互斥。
  3. 修改名称、物种、品系、性别、来源、价格、状态、饲养箱、日期、体重、体长和备注。
  4. “生理绝食／冬化休眠”开启后，会降低未进食提醒权重，适合冬化或发情期；它不是医疗诊断。
  5. 在“照料周期”分别修改喂食、换水和清洁模式，最后点击“完成”。

查看饲养成本

路径宠物 → 选择宠物 → 饲养成本

成本汇总包含购入价格，以及与该宠物或其饲养箱关联的食品、药品、垫材等消耗成本。只有库存已设置价格并通过记录扣减时，消耗才会进入成本统计。

04

记录照料与批量操作

快捷记录

路径概览右上角“+” → 选择记录类型

可记录喂食、体重、蜕皮、排泄、换水、清洁、环境读数，以及使用／更换耗材。也可以在宠物卡片上长按进入针对该宠物的快捷记录。

记录单次喂食

路径“+” → 喂食

  1. 选择宠物和发生时间。
  2. 选择饵料类型，并自由选择按“只、份、克或毫升”记录；可另外填写总重量。
  3. 选择正常进食、辅助喂食、主动拒食或喂后吐食。
  4. 如需自动扣库存，选择匹配计量方式的饵料，并确认“已消耗、放回库存或已丢弃”。
  5. 按需填写补剂、备注和照片，然后保存。
进食结果不等于库存结果例如拒食后可以把饵料放回，也可以标记丢弃；只有“已消耗”或“已丢弃”才会扣减库存并计入成本。

批量照料

路径概览右上角“+” → 批量照料

  1. 选择喂食、换水或清洁，并按饲养箱或物种分组。
  2. 批量喂食时选择饵料种类、计量单位、每只喂食量和可选库存。
  3. 勾选本次需要处理的宠物；未勾选的不会生成记录。
  4. 逐只选择完成、拒食、跳过或异常，确认后点击“提交”。
05

饲养箱与环境

查看和编辑饲养箱

路径宠物 → 切换到饲养箱筛选 → 选择饲养箱

饲养箱详情汇总尺寸、关联宠物、设备、目标温湿度、最近读数和维护状态。编辑箱体时修改关联宠物，会同步更新宠物的箱体归属。

添加环境读数

路径概览“+” → 环境读数，或 宠物／饲养箱详情 → 环境

  1. 选择饲养箱、日期和时间。
  2. 填写温度、湿度及可选备注。
  3. 保存后会进入环境趋势；超出目标区间时可能生成环境异常。

处理环境异常

路径设置 → 环境异常处理

可根据最新读数刷新异常，查看进行中和历史异常。正常读数会按规则关闭对应异常；App 只提供记录和提示，不能代替现场检查设备与宠物状态。

06

过往记录

路径底栏“过往”

  1. 时间线默认把最新日期放在顶部。同一天的记录也按最新时间优先。
  2. 点击顶栏日期按钮打开日历；没有内容的日期会禁用。
  3. 点击筛选按钮按记录类型筛选，或使用“回到今天”。
  4. 点击记录查看详情；通过详情页的“编辑”修改内容，或使用菜单标记完成／未完成。
  5. 删除记录后，它会进入“设置 → 历史追溯与回收站”；关联的库存消耗会尝试回滚。
07

耗材、库存与成本

添加耗材

路径底栏“耗材” → 右上角“+”

  1. 选择食品、药品、垫材或设备，填写名称。
  2. 填写购买数量和购买单位，例如 2 袋、1 盒或 1 瓶。
  3. 食品、药品和垫材可再设置每个购买单位的实际含量，并选择只、份、克或毫升作为消耗单位。
  4. 填写购买价格后，系统会按实际消耗量换算成本。
  5. 按需开启低库存提醒、关联饲养箱和更换周期，然后保存。

使用或更换耗材

路径概览“+” → 使用／更换耗材

  1. 选择库存项目和实际使用数量。
  2. 指定宠物或饲养箱。若宠物已关联箱体，作用范围会规范为整个箱体；直接选择箱体也会覆盖箱内宠物。
  3. 垫材消耗可同时刷新该箱体的更换状态。保存失败或库存不足时，不会只完成一半。

查看库存流水

路径耗材 → 某项右侧“管理”

“消耗耗材”用于实际使用并要求指定对象；“其他记账”用于入库、报废、盘点调整等。流水会保留数量、单位、时间、关联记录和回滚状态。

08

专业档案

路径宠物 → 选择宠物 → 专业档案

就诊记录记录机构、医生、症状、诊断、处置、费用、复诊日期和附件。
用药疗程建立剂量计划，按“已服、漏服、跳过”执行并在结束时回顾。
检疫流程管理检疫检查项、结果备注、照片和解除记录。
谱系关联父本、母本和遗传备注，查看家系关系。
繁育与窝蛋记录配对、产蛋、逐蛋状态、出壳，并为幼体建立档案。
专业导出按用途生成可分享的档案；分享前请核对隐私和授权。
医疗边界

这些功能用于整理记录，不提供诊断、处方或治疗建议。出现异常或紧急情况时，请联系合格的异宠兽医。

09

提醒与关注项

开启日常提醒

路径设置 → 照料提醒

先开启“日常照料提醒”，再设置提醒时间及喂食、换水、清洁、用药剂量和复诊提醒。首次开启时需要允许 iOS 通知权限。

调整关注阈值

路径设置 → 专业工具 → 关注项阈值

阈值用于控制体重、环境、未进食等关注提示。通知可能因系统权限、低电量模式或设备状态延迟，请始终以人工检查为准。

个性化、语言与单位

个性化

路径设置 → 个性化

  • 选择跟随系统、浅色或深色外观。
  • 选择预设强调色，或使用色板末尾的系统自定义取色器。
  • 决定应用背景是否跟随强调色，并选择浅色背景预设。
  • 开启或关闭性别符号颜色。
  • 选择首页状态卡背景图片，进入 16:9 裁切页拖动和缩放；图片只保存在本机，除非你主动把照片同步选项打开。

语言与单位

路径设置 → 语言 / 单位系统

语言可跟随系统，也可在 App 内选择简体中文、繁體中文、English、日本語、한국어、Español、Русский或ไทย。单位系统会影响重量、长度和温度的输入与显示，但不会改写你保存的业务含义。

11

iCloud 同步

路径设置 → 数据管理 → iCloud 同步

  1. 打开“iCloud 同步”。首次安装时默认关闭；开启前请确认系统已登录 iCloud，并为栖记开放 iCloud 权限。
  2. 主同步包含宠物、照料、任务、环境、医疗、检疫、繁育、耗材、审计和回收站数据。
  3. 照片同步是单独的开关，默认关闭。关闭它不会删除本机照片，也不会上传或下载照片。
  4. 点击“立即同步”可手动执行。App 启动、回到前台或本机成功保存后也会按条件同步。
  5. 离线时可继续记录；重新联网后按单条档案合并。同一条内容发生冲突时，以最近修改为准。
不是实时协作当前没有后台静默推送。另一台设备的修改通常会在本机下次进入前台或手动同步时获取。
12

备份、恢复与导出

完整备份

路径设置 → 数据管理 → 导出完整备份（ZIP）

ZIP 会包含档案、照料日志和关联原图。文件先在本机生成，之后由你通过系统分享面板保存到“文件”、隔空投送或其他目标。

定期自动备份

路径设置 → 数据管理 → 定期自动备份

开启后选择间隔天数。自动备份保存在本机可管理的位置；设置页会显示最近备份和失败状态。仍建议定期把重要备份复制到你信任的外部位置。

从备份恢复

路径设置 → 数据管理 → 从备份恢复

  1. 选择栖记 ZIP 备份包或旧版 JSON 档案。
  2. 核对内容概览。恢复会覆盖当前本机数据和照片。
  3. 确认“覆盖并恢复”。系统会先创建本地安全回退副本，再执行完整性检查和恢复。

表格和月报

  • CSV：设置 → 数据管理 → 导出明细表格，可在 Excel 或 Numbers 中分析。
  • PDF：设置 → 数据管理 → 生成照料月报，用于查看或分享阶段摘要。
13

栖记 Pro 与购买

路径设置 → 栖记 Pro

免费版最多管理 3 只活跃宠物，基础档案、照料记录、提醒和备份不会因未订阅而删除。Pro 页面会显示当前可售的月订阅、年订阅和永久买断，实际价格和币种由 Apple 根据 App Store 地区提供。

  • 点击方案后，使用“解锁栖记 Pro”发起 Apple 内购。
  • 已购买但未识别时，点击“恢复购买”。恢复会请求 Apple 重新核对当前账户权益。
  • 订阅用户可从 Pro 页面进入 Apple 的订阅管理界面切换或取消方案。
  • 永久买断不会自动续费。当前 Pro 权益不包含未来可能推出的 AI 服务和相关用量。
14

删除与历史追溯

删除宠物

路径宠物 → 选择宠物 → 编辑 → 删除此爬宠档案

宠物档案删除属于高影响操作，相关照料记录与照片会一并处理。操作前建议先导出完整备份。

恢复误删记录

路径设置 → 流程与追溯 → 历史追溯与回收站

这里可以查看被删除的记录并按支持范围恢复。恢复记录时，相关库存与照片引用会按现有数据关系重新校验。

删除 App

删除 App 会移除其本机应用空间中的数据；已导出的 ZIP、JSON、CSV 或 PDF，以及已同步到 iCloud 私有数据库的内容，不会因删除本机 App 自动全部消失。

15

常见问题与排查

为什么首页没有显示某一天的照料计划？

先确认概览顶部选中的日期，再进入宠物“编辑 → 照料周期”检查该项目的间隔／循环和周期开始日期。临时调整可在“宠物详情 → 照料计划 → 添加临时调整”中查看。

为什么库存没有自动扣减？

检查库存是否启用了实际消耗单位、喂食记录使用的单位是否匹配，以及记录中是否选择了库存项目和“已消耗／已丢弃”。“放回库存”不会扣减。

为什么提醒没有出现？

检查“设置 → 照料提醒”总开关和分类开关，再到 iOS“设置 → 通知 → 栖记”确认权限。系统仍可能延迟通知，请不要把通知作为唯一照护依据。

为什么 iCloud 显示不可用或同步失败？

确认系统已登录 iCloud、iCloud Drive 可用、网络正常，并在同步页点击“立即同步”。关闭同步不会删除本机数据。持续失败时先导出完整备份，再联系开发者并提供不含私人档案的错误文字。

为什么价格显示美元或其他币种？

内购价格由 Apple 按当前 App Store 商店地区返回，与 App 语言或系统地区不一定相同。请检查“设置 → Apple 账户 → 媒体与购买项目”的商店地区。

如何联系开发者？

路径为“设置 → 关于 栖记 · Terria → 联系开发者”，会打开邮件并发送至开发者邮箱。也可使用本网站的 GitHub Issues，但请勿公开上传照片、备份或个人信息。

Getting started

The five tabs

OverviewToday’s care, maintenance, growth summary, and recent activity.
PetsPet profiles, cards, enclosures, and professional records.
HistoryBrowse, filter, edit, or delete records by date.
SuppliesFood, medication, substrate, equipment, inventory, and cost.
SettingsReminders, appearance, language, sync, backups, Pro, and legal information.

Add your first pet

PathOverview “+” → Add Pet

  1. Enter a name and select a species. Search by Chinese name, English name, or trait, or filter by category.
  2. Optionally enter morph, sex, source, and purchase price.
  3. Add acquired date, birth date, current weight, and current length. Units follow Settings → Unit System.
  4. Assign an existing enclosure or choose Not Assigned and create one later.
  5. Configure feeding, water-change, and cleaning schedules independently in interval or cycle mode.

15

Troubleshooting

Why is a scheduled item missing on the Overview?

Verify the selected date, then open Pet → Edit → Care Schedules and check the mode and cycle start date. Temporary overrides appear under Pet Detail → Care Plan.

Why did inventory not decrease?

Check the item’s base consumption unit, the unit used in the feeding record, and whether inventory plus Consumed/Discarded was selected. Returned does not reduce stock.

Why did a reminder not appear?

Check Settings → Care Reminders and iOS Settings → Notifications → Terria. System conditions can delay notifications, so never rely on them as the only care check.

Why is iCloud unavailable or failing?

Confirm iCloud sign-in, iCloud Drive, network access, and tap Sync Now. Turning sync off does not remove local data. Export a backup before extended troubleshooting.

Why is the price in US dollars or another currency?

Apple returns prices for the current App Store storefront, which can differ from app language or device region. Check the storefront under Apple Account → Media & Purchases.

How do I contact the developer?

Use Settings → About Terria → Contact Developer. You can also open a GitHub Issue, but never post private photos, backups, or personal information publicly.
